**תאריך:** 2026-08-20 · **סטטוס:** ממתין למימוש (נשמר לפני טיפול בבאגים באדמין) · **ענף:** FIX_DEV_2602

## הבקשה המקורית (מהמשתמש)

במסך הפתיחה הראשון תהיה אפשרות לרישום לקוח חדש — בתנאי שלא נרשם עדיין:

- לקוח שהוריד את האפליקציה מהחנות וטרם נרשם יראה בכפתור התחתון **"רישום ראשוני"** במקום **"בחירת עסק"** — אותו כפתור, אותו מיקום, טקסט שונה.
- לאחר שנרשם — בכל כניסה יופיע הכפתור הרגיל "בחירת עסק".
- הקישור הקיים "אין כרטיסייה? הרשמ/י לקבלת כרטיסייה" (אחרי בחירת עסק) **נשאר** — הפיתוח החדש הוא אלטרנטיבה, לא תחליף.
- הרישום ממסך הפתיחה נטול שיוך לעסק → נדרש שדה בחירת עסק, ו/או שקריאת מחרוזת NFC תכתיב עסק כברירת מחדל.
- הצטרפות מרחוק קיימת גם היא ומחייבת בחירה ידנית.

## ממצאי הבדיקה (בוצעה 2026-08-20)

### 1. הסיכון המרכזי: הכפתור "בחירת עסק" מצויר בתוך PNG
מסך הפתיחה `app/(tabs)/business_selector.tsx` הוא `ImageBackground` של `assets/images/new_entry.png` עם `resizeMode="cover"`. הכפתור הוורוד מצויר בתמונה; הלחיצה נקלטת בשטח מגע שקוף `selectBusinessArea` (שורות ~854–874) הממוקם בפיקסלים קשיחים בשלוש וריאציות: iOS (`bottom:119`), Android (`bottom:83`), טאבלט.

**לא ניתן להחליף טקסט בקוד.** שתי גישות:

| גישה | תיאור | סיכון |
|---|---|---|
| **א. החלפת תמונה (מומלץ)** | גרסה שנייה של `new_entry.png` עם "רישום ראשוני"; בחירת תמונה לפי מצב רישום; אותו שטח מגע, onPress מתפצל | כמעט אפס — הטקסט זז עם התמונה; משתמשים רשומים רואים את המסך הקיים ללא שינוי |
| **ב. כפתור אמיתי מעל המצויר** | Text/TouchableOpacity אטום מכסה את הכפתור המצויר | גבוה — בגלל `cover` מיקום הכפתור המצויר משתנה לפי יחס מסך; אי-יישור נראה כ"כפתור כפול"; תחזוקת 3 וריאציות |

הסגנונות בקובץ לוקאליים בלבד — אין זליגת CSS למסכים אחרים.

### 2. הטופס הקיים כבר תומך ברישום ללא עסק משויך
`app/(tabs)/newclient_form.tsx` כולל כבר שדה חובה **"שם העסק לצירוף\*"** (שורה ~504) עם בורר מכל העסקים + חיפוש + מודאל "בקשת צירוף עסק חדש". העסק מה-BusinessContext הוא רק ברירת מחדל (שורות 48–52); בהגעה ללא עסק — השדה ריק והלקוח בוחר.

**מסקנה: אין לשכפל טופס.** "רישום ראשוני" מנווט ישירות ל-`newclient_form`.

### 3. NFC כברירת מחדל לעסק
- **אפליקציה מותקנת:** תג NFC (`https://punchcards.digital/business/{code}`) → `app/business/[code].tsx` → `setBusinessCode` → customers-login. כניסה משם לטופס הרישום ממלאת את העסק אוטומטית. **עובד כבר היום.**
- **אפליקציה לא מותקנת (הפניה לחנות):** קוד העסק אובד. iOS — אין install referrer (נדרש Branch/AppsFlyer = תלות כבדה). Android — אפשרי עם Play Install Referrer (ספרייה נייטיבית + שינוי עמוד ההפניה + build EAS). **המלצה: לא לפתח כעת** — שדה בחירת העסק בטופס מכסה את המקרה.

### 4. זיהוי "נרשם כבר" — אין דגל קיים, יש להגדיר
מועמדים קיימים: `saved_phone` (AsyncStorage, נכתב אחרי כניסה מוצלחת ב-customers-login), `biometric_phone` (SecureStore).

**תנאי מוצע:** רשום = קיים `saved_phone` **או** `biometric_phone` **או** דגל חדש `initial_registration_done` (ייכתב בסיום רישום מוצלח — מסך thank_you / הצלחת יצירת כרטיסייה).

**נקודות חובה:**
1. **לקוח שצורף מרחוק** ע"י העסק מעולם לא נרשם באפליקציה אך הוא לקוח. חובה נתיב משני במצב "לא רשום" — קישור טקסט "כבר יש לך כרטיסייה? לבחירת עסק" (או הסתמכות על "שנה עסק" שבטופס). בלעדיו השינוי שובר תרחיש קיים.
2. **התקנה מחדש** מאפסת את הדגל — הכפתור יחזור ל"רישום ראשוני"; הנתיב המשני מונע חסימה.
3. קריאת הדגל אסינכרונית — עד לתשובה להציג את התצוגה הרגילה ("בחירת עסק") כדי למנוע הבהוב אצל ותיקים.

## תוכנית מימוש מומלצת

1. **נכס גרפי:** גרסת `new_entry_register.png` — זהה ל-`new_entry.png` פרט לטקסט הכפתור "רישום ראשוני". (חלופת ביניים אם אין קובץ מקור עיצובי: מלבן בצבע הכפתור + טקסט מעל, מוגבל למצב "לא רשום" בלבד.)
2. **`business_selector.tsx`:**
   - state `isRegistered: boolean | null`; ב-mount לקרוא `saved_phone` / `biometric_phone` / `initial_registration_done`; `null` → להציג את התצוגה הרגילה.
   - בחירת `source` של ה-ImageBackground לפי המצב.
   - `onPress` של `selectBusinessArea`: רשום → מודאל בחירת עסק (קיים); לא רשום → `router.push('/(tabs)/newclient_form')` (ללא עסק ב-Context, או עם עסק אם הגיע מ-NFC).
   - במצב "לא רשום": קישור משני "כבר יש לך כרטיסייה? לבחירת עסק" שפותח את המודאל הקיים.
3. **כתיבת הדגל `initial_registration_done`:** בהצלחת רישום ב-`newclient_form` (לפני מעבר ל-thank_you), ובנוסף בהצלחת login ב-`customers-login` (ליד כתיבת `saved_phone`).
4. **ללא** install-referrer בשלב זה; **ללא** טופס חדש; **ללא** שינוי בקישור "אין כרטיסייה?".

**קבצים מושפעים:** `app/(tabs)/business_selector.tsx`, `app/(tabs)/newclient_form.tsx` (כתיבת דגל), `app/(tabs)/customers-login.tsx` (כתיבת דגל), נכס גרפי חדש ב-`assets/images/`.
**תלויות חדשות:** אין.
